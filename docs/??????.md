# 手边事 · 前期开发准备文档

> 项目定名：**手边事**
> 释义：放在手边、随手安排、马上就要处理的事情，契合拖拽规划短周期任务的核心定位，生活化、好记，适配极简现代 UI。
> Slogan：拖拽安排眼下要做的事

## 一、项目概述

### 1.1 项目定位

一款**极简轻量化安卓待办事项 APP**，无复杂打卡、倒计时、分类、统计等冗余功能。核心依托**拖拽交互**实现待办任务的快速筛选、临时规划与完成记录，帮助用户直观梳理 1–2 小时内的即时待办事项，解决琐事繁多、临时工作计划混乱的问题。

### 1.2 核心使用场景

1. 日常居家：洗漱、做饭、家务、亲子陪伴（看动画、洗漱）等临时事项规划；
2. 日常工作：短周期（1–2 小时）碎片化工作任务快速排布；
3. 生活衔接场景：接孩子放学、出行、办事等衔接式事项临时安排。

### 1.3 核心特点

极简设计、操作直观、仅保留「事项录入、拖拽排布、撤回、完成删除」核心功能，低内存占用、无广告、无冗余权限，**自主原创现代化 UI，符合当代主流 APP 审美质感**。

## 二、整体功能架构

本 APP 分为**安卓前端客户端** + **简易后台管理端**两大模块，无用户登录、无网络同步、无云服务，数据本地存储。

1. 后台管理端：仅负责**新增、管理全部基础待办事项库**；
2. 前端首页：核心交互页面，实现事项拖拽、规划、撤回、完成删除全操作。

## 三、详细功能需求说明

### 3.1 后台管理端功能（核心：事项库管理）

仅需基础极简功能，用于录入所有可使用的待办事项模板，永久保存在本地，可反复调用：

1. **新增事项**：手动输入文字内容（如刷牙、洗脸、上班、学习做饭、孩子洗漱），点击保存，自动加入全局事项库；
2. **查看全部事项**：后台展示所有已录入的待办事项列表；
3. **删除/编辑已有事项**：支持对录入错误、不再使用的事项进行删除，支持修改事项文字内容；
4. **数据本地持久化**：所有录入的事项库数据，重启 APP 不丢失，无需联网、无需账号。

### 3.2 前端首页核心功能（核心交互页面）

首页固定**上下双区域布局**，为 APP 唯一核心使用页面，无其他多余页面：

#### 3.2.1 页面区域定义

1. **上区域：即时待办区（临时执行区）**：存放用户筛选出的 **1–2 小时内需要完成的事项**，为当前优先执行任务；
2. **下区域：全部事项库区（素材区）**：展示后台录入的**所有未被选用的原始待办事项**，作为任务素材池。

#### 3.2.2 核心拖拽交互规则（严格匹配需求）

1. 正向拖拽：从**下方全部事项区**拖拽任意事项到**上方即时待办区**，下方对应事项自动消失，仅保留未拖拽的剩余事项；
2. 反向拖拽：已拖入上方区域的事项，可**重新拖拽回下方事项库区**，撤回本次规划，事项恢复至原始素材状态；
3. 完成删除操作：上方即时待办区的事项，支持**单独删除单条事项**，删除代表任务已完成，删除后数据彻底清空，不会回到下方素材区；
4. 交互逻辑闭环：
   - 拖上去 = 加入待办计划；
   - 拖回来 = 取消本次计划；
   - 点「完成」= 任务完成结束。

#### 3.2.3 辅助基础功能

1. 双区域实时刷新：拖拽、撤回、删除操作后，页面即时更新，无延迟、无错乱；
2. 无数量限制：上下区域可自由放置多条事项，适配多任务场景；
3. 拖拽启动方式：采用**长按卡片启动拖拽**（行业标准做法，避免与列表滚动手势冲突）；删除一键生效。

### 3.3 全局通用规则

1. 数据全部**本地存储**，无需联网、无云同步、无用户注册登录；
2. 无广告、无推送、无后台自启动；
3. 适配主流安卓手机屏幕，布局自适应、UI 统一现代化风格。

## 四、UI 页面设计规范（现代极简原创 UI）

### 4.1 整体设计原则

采用**当代安卓主流极简磨砂质感 UI**，自主原创设计，遵循「轻量化、高级干净、低饱和、层次分明、交互柔和」原则。使用**圆角、微阴影、渐变分层、轻微动效、低饱和配色**，简约但不简陋，高级且不花哨。

### 4.2 全局统一视觉规范

1. **配色体系（固定高级极简色系）**
   - 主色调：低饱和静谧蓝 `#4E7CF6`（按钮、选中、交互强调）
   - 背景色：全局浅灰白 `#F5F6FA`，上区浅蓝 `#EFF3FC` 色差分层
   - 文字色：主文字深灰黑 `#1A1D26`、辅助浅灰 `#8A90A0`
   - 禁止：大红大绿、高饱和艳丽、复杂多彩渐变
2. **圆角规范**：卡片、按钮、输入框统一大圆角（16–22dp）
3. **阴影规范**：任务卡片超低柔化阴影（elevation 2dp），营造悬浮层次感
4. **字体规范**：系统默认无衬线黑体，字号层级分明
5. **分割方式**：取消粗黑线，采用「色差分层 + 留白间距」

### 4.3 首页核心页面 UI 细节

1. 竖向二分屏：上区浅蓝卡片式、下区浅灰底色，色差分层区分，无硬分割线；
2. 区域标题：轻量化小字标签；
3. 任务卡片：独立圆角白色卡片，拖拽时系统阴影悬浮高亮，完成删除平滑淡出；
4. 空状态：浅灰极简提示文字。

### 4.4 后台管理页 UI 细节

1. 顶部输入模块：圆角输入框 + 圆角主色按钮；
2. 事项列表：圆角卡片式，含「待办中 / 素材库」状态标签，编辑、删除按钮；
3. 整体留白合理、疏密均匀。

### 4.5 交互动效规范（轻量高级）

1. 拖拽：卡片跟随手指顺滑悬浮（系统 DragShadow）；
2. 按钮点击：Material 波纹反馈；
3. 增删数据：页面即时刷新，卡片平滑过渡；
4. 所有动效轻量化、低时长，不花哨。

## 五、技术开发方案（适配安卓原生开发）

### 5.1 开发技术栈

1. 开发语言：Kotlin（原生主流语言，轻量化、兼容性强）；
2. 开发框架：原生 Android SDK（View + RecyclerView），无第三方臃肿框架；
3. 拖拽核心技术：Android 原生拖拽 API（`startDragAndDrop` / `OnDragListener`）；
4. 本地数据库：Room 轻量数据库（本地持久化）。

### 5.2 核心技术实现要点

1. 二分屏布局：LinearLayout 竖向权重分布，上下区域比例协调；
2. 拖拽逻辑：下区拖入上区 → `isPinned=true`；上区拖回下区 → `isPinned=false`；上区「完成」→ 删除数据；
3. 数据绑定：Room Flow 实时绑定视图，增删改即时刷新；
4. 兼容性：minSdk 26（Android 8.0+），适配手机、平板；
5. UI 适配：全局 dp、自适应布局。

## 六、功能优先级排序（开发顺序）

1. 一级（必做）：后台新增 + 本地存储；首页上下二分屏；下→上拖拽；上区删除（完成）。
2. 二级（完善）：上→下拖拽撤回；后台编辑/删除；UI 自适应。
3. 三级（极致）：现代极简 UI 全套落地；拖拽悬浮、动效优化；空状态完善。

## 七、禁止开发内容（规避冗余功能）

1. 禁止：用户登录、注册、云同步、数据备份；
2. 禁止：倒计时、闹钟提醒、重复待办、分类标签、优先级设置；
3. 禁止：统计报表、日历视图、小组件、分享功能；
4. 禁止：广告、开屏页、欢迎页、主题切换、字体调节；
5. 禁止：老旧简陋样式、高饱和花哨 UI、第三方付费 UI 模板，全程自主原创现代极简 UI。

## 八、交付与运行要求

1. 最终输出：安卓安装包（APK），可直接安装运行；
2. 运行要求：无需联网、无额外权限；
3. 整体要求：启动快、占用低、操作零卡顿、逻辑无 BUG；
4. UI 要求：全页面统一现代高级审美，媲美主流轻量化工具类 APP。
